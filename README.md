# desconto

Este é um script simples em Python que automatiza o cálculo de descontos para produtos. O usuário digita o nome e o valor de um produto e o sistema aplica automaticamente uma porcentagem de desconto específica com base em faixas de preço predefinidas.
Como FuncionaO programa solicita o nome do produto.O programa solicita o valor atual do produto.O sistema avalia o valor informado e aplica uma regra de negócio (ex: produtos acima de R$ 100 recebem 10% de desconto).O terminal exibe o valor original, o desconto aplicado e o valor final a ser pago.
