# desconto

Este é um script simples em Python que automatiza o cálculo de descontos para produtos. O usuário digita o valor de um produto e o sistema aplica automaticamente uma porcentagem de desconto específica com base em faixas de preço predefinidas.
Como Funciona O programa: solicita o valor do produto. O sistema avalia o valor informado e aplica uma regra de negócio (ex: produtos acima ou igual a R$ 200 recebem 10% de desconto).O terminal exibe o valor original, o desconto aplicado e o valor final a ser pago.
